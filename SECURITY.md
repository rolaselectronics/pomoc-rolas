# Bezpieczeństwo

Problemy bezpieczeństwa prosimy zgłaszać prywatnie na adres kontaktowy Rolas
Electronics, bez publikowania danych dostępowych ani szczegółów aktywnej sesji.

Pomoc Rolas uruchamia zdalny dostęp wyłącznie po świadomej akcji użytkownika.
Widoczne okno pokazuje identyfikator, a jego zamknięcie kończy proces UltraVNC
i usuwa pliki tymczasowe.
